# Проверка и усиление защиты PLIPLY — 21.10.2026

Изменения подготовлены поверх Draft PR #1, исходная вершина
`5be37f996906f398e4122f59d06b166a752bdc00`. Сохранены оформление главной,
тексты, цвета, шрифты, HTML/CSS/JS и GitHub Pages. Это техническое исправление,
без внедрения новых дизайнерских макетов.

## Исправления

1. На 14 HTML-страницах действует CSP: запрещены встроенный JavaScript,
   обработчики событий в разметке, внешние скрипты, eval, объекты, вложенные фреймы,
   подмена base URL и обычная отправка форм. XHR ограничен HTTPS Formspree.
   Встроенные стили оставлены для совместимости с существующим оформлением.
2. Three.js r128, GSAP 3.12.2 и ScrollTrigger 3.12.2 размещены локально, без смены
   версии или рисунка анимации. Их байты совпали с прежними SRI из PR; сохранены
   сведения о происхождении и лицензиях. Все четыре собственных JS-файла также
   проверяются браузером по SRI. Изменение версии требует согласованного изменения
   npm lockfile, локальных файлов и загрузчика.
3. До создания Three.js renderer проверяется доступность контекста WebGL.
   При отказе остаётся рабочий статичный интерфейс, без ошибки библиотеки.
4. Форма проверяет длины повторно в транспорте, не отправляет неожиданные поля,
   cookies и referrer, запрещает перенаправления. Неожиданная ошибка транспорта
   снимает блокировку кнопки; текст сохраняется, ложный успех не показывается.
   Endpoint с пробелами, завершающим переводом строки, другим host/query/hash
   не допускается. Подключение сервиса по-прежнему пустое; реальные письма не шли.
5. Девять прежних Work/Stats HTML показывают сообщение о конфиденциальности.
   Публичный sitemap больше не рекламирует эти страницы. Старые изображения
   исключены из Pages, включая прямые пути; не ограничились удалением ссылок.
   Архивы проверки, инструменты, manifest и неиспользуемый app.js тоже исключены.
6. Старый Contact с противоречащими реквизитами отсылает к реквизитам главной;
   адрес и регистрационные данные не угадывались. Почта adm@pliply.pro сохранена.
7. Добавлена полезная страница 404. Подготовлены автоматические проверки с
   закреплёнными SHA официальных Actions и read-only token. Они не публикуют сайт.

## Пределы проверки и оставшиеся действия

- Внутренний HTTP-предпросмотр использует те же исходные файлы и фикстуры.
  Только `upgrade-insecure-requests` убран из QA-копии: внутренний сервер не
  предоставляет TLS. В production-исходниках директива сохранена. Это не заменяет
  включение Enforce HTTPS в настройках GitHub Pages.
- WebGL в текущем облачном Chromium недоступен: проверен реальный отказ и
  работоспособность интерфейса. Живую анимацию в этой среде подтвердить нельзя.
  Повторная проверка мобильного диалога в iframe не завершена; предыдущее
  подтверждение находится в stage-1. Также не проверялись физические телефоны,
  экранная клавиатура и screen reader.
- Опубликованная версия по-прежнему принимает HTTP, а github.io понижает схему
  до HTTP. Нужна штатная настройка Enforce HTTPS и повторный замер цепочек.
  Файлом репозитория эта настройка не включается.
- Backend формы не подключён. Рабочий путь — подготовка письма в почтовой
  программе. Для веб-отправки нужен подтверждённый endpoint и тест получения.
- Исходные проекты и аналитика уже находятся в публичном GitHub и его истории.
  Исключение из Pages не удаляет эти копии и поисковые кэши. Изменение видимости
  репозитория/очистка истории — отдельное действие с последствиями для Pages и
  текущего PR. В этой ветке историю не переписывали.
- MFA, активные сессии, права приложений и регистратора не проверены по коду.
  Нет основания заявлять, что аккаунт точно не взломан или что «вирусов нет».
  Проверка исходников не является антивирусным исследованием устройств.
- GitHub Pages не настраивает HSTS, X-Frame-Options или frame-ancestors через meta
  или `_headers`. Фиктивных заголовков не добавлено; для этих контролей нужен
  поддерживающий их HTTP-слой. DNS и корпоративная почта не менялись.
