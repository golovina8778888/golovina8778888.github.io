# Форма: подготовлено, подключение ожидает решения

Проверены текущее дерево, документация и 57 исторических HTML/JS/config blobs:
рабочего endpoint, serverless-функции, form-ID или интеграции нет. Старые формы
Subscribe имели только `action="#" onsubmit="return false;"` — это заглушки
([результат поиска](handler-search.json)). Исходный `sendEmail()`
только присваивал `window.location.href=mailto:…` и закрывал окно. Наличие Zoho
MX не создаёт веб-обработчик. Сторонние почтовые ящики/аккаунты не исследовались.

## Что работает сейчас

Подписанные email/message, валидация, доступные ошибки, сохранение текста при
закрытии окна и ошибках, явное открытие почтовой программы, копирование текста и
прямая ссылка adm@pliply.pro. Сайт не объявляет письмо отправленным. Длинный
mailto (>1800 символов после кодирования) заменяется предложением скопировать
сообщение: поддержка длинных ссылок почтовыми программами ненадёжна.

`contact-config.js` содержит **пустой endpoint**. Сетевая веб-отправка отключена.
Если подключить одобренный Formspree form-ID, адаптер уже предусматривает JSON
POST, тайм-аут 15 с, блокировку повтора на время запроса, отдельные сообщения
для 400/422, 429, 5xx и неопределённого результата. Успех требует JSON с `next`
в формате официального SDK (поле не используется для навигации),
а не просто HTTP 200; интерфейс пишет только «сервис принял», не «письмо доставлено».
После приёма повтор заблокирован до редактирования. Автоповторов нет.
Текст не удаляется и не пишется в аналитику или браузерное хранилище.

## Минимальный вариант: Formspree

По [официальному прайсу](https://formspree.io/plans), проверенному 21.10.2026:
Free — $0, 50 обращений/месяц, история 30 дней; AJAX и ограничение домена доступны.
Этот тариф позиционируется для тестирования/разработки; подходит для приёмочного
пилота. Personal — $15 USD/месяц при помесячной оплате либо $120 USD/год,
200 обращений/месяц. Налоги и валютная конверсия зависят от оплаты.
Платный тариф не оформлялся. Владелец выбирает достаточную квоту до запуска.

Точные шаги владельца/администратора:

1. Создать/использовать принадлежащий владельцу аккаунт Formspree, подтвердить
   доступ к adm@pliply.pro. Создать New Form → `PLIPLY enquiries`, выбрать
   **Target Email: adm@pliply.pro**, включить email-уведомления. Из Integration
   скопировать URL `https://formspree.io/f/FORM_ID`. Form-ID публичный;
   API-ключи, SMTP-пароли и секреты в сайт не добавлять.
2. Project Settings → Restrict to Domain: **pliply.pro** без протокола и www.
   Это покрывает поддомены. Оставить referrer-policy `strict-origin-when-cross-origin`.
   Формы с иных доменов могут попадать в Spam; localhost не использовать с этим
   рабочим endpoint. Локальная проверка использует только встроенный mock.
3. Включить стандартную фильтрацию Formshield и контролировать Spam и квоту.
   Поле `_gotcha` предусмотрено; проверка на клиенте лишь дополнительная и
   обходится ботами. Требуется серверная фильтрация сервиса.
   Если потребуется CAPTCHA, согласовать её и внедрить отдельным изменением с
   проверкой доступности и отказов; checkbox-поток не объявляется готовым AJAX.
4. Согласовать использование третьей стороны для email/message, срок хранения
   и ссылку на уведомление PLIPLY об обработке данных. Текст текущей формы при
   подключении прямо называет Formspree. Адрес обработчика/правила компании
   не придуманы вместо владельца.
5. В отдельном изменении заполнить `endpoint` в `contact-config.js` точным URL.
   Используются поля `email`, `message`, `_subject`, `language`, `_gotcha`;
   `email` служит адресом для ответа. Никаких файлов или чувствительных полей.
   Код принимает только HTTPS Formspree `/f/<id>` без query. Для другого сервиса
   сначала изменить проверку адреса и контракт ответа, не подставлять URL вслепую.
6. После отдельного разрешения: одно помеченное тестовое обращение с pliply.pro.
   Сверить JSON-подтверждение, запись Dashboard/Spam и получение в adm@pliply.pro
   (включая Spam), проверить возможность ответа и записать время/идентификатор.
   Только подтверждение получателя закрывает проверку доставки.

DNS, MX, SPF, DKIM и DMARC для стандартных уведомлений Formspree не меняются.
Настройка собственного отправляющего домена не входит в этот вариант.

## Доказательства и открытые границы

`form-browser.json`: шесть ответов локального mock — принятие, 429, 422, 503,
невалидный ответ 200 и тайм-аут. `_tests/contact.test.cjs` проверяет транспорт без
сети; повтор и редактирование проверены отдельно в браузере. `_tools/preview.py`
не отправляет писем, не сохраняет тела запросов и исключён из Pages.
Провайдер, его антиспам, квота, реальный CORS и доставка пока не проверены.
