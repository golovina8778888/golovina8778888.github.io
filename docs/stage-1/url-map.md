## Сохранность

`retained-sources/` содержит **12 оригинальных публичных старых HTML и 3 версии
из истории** до правок; SHA и SHA-256 — [manifest](preserved-manifest.json).
Весь существующий набор изображений остаётся в репозитории; ни один исходный
asset не удалён и не перезаписан. Полная исходная главная/история остаются в Git
на базовом коммите и в локальной папке аудита `pliply-audit-2026-10-21/source`.
Копии доказательств исключены из Pages, не становятся новыми публичными URL.
Четыре отсутствующих статистических изображения и один постер не найдены;
их байты не заявляются сохранёнными. Опечатка Phobia исправлена точным совпадением.
